Home Assistant · XEGA 4G · ESP32-2432S028

UBox CYD — instalator

Wgraj firmware jednym kliknięciem przez USB. Nie potrzebujesz VS Code ani PlatformIO.

1. Wgraj firmware

  1. Podłącz CYD przez USB do komputera.
  2. Otwórz stronę w Chrome lub Edge na Windows i kliknij „Połącz / Zainstaluj”.
  3. Wybierz port płytki (u Ciebie COM4) i zaakceptuj instalację.
  4. Poczekaj na zakończenie wgrywania. Nie odłączaj urządzenia podczas flashowania.
Instalacja przez USB wymaga Chrome lub Edge na komputerze z obsługą Web Serial, na stronie HTTPS. Dostęp do portu szeregowego został zablokowany przez przeglądarkę.

Przy pierwszej instalacji zawartość flash ESP32 może zostać wyczyszczona. Projekt przeznaczony jest wyłącznie dla klasycznego CYD ESP32-2432S028 z ekranem ILI9341, a nie dla wariantów ESP32-S3/P4.

2. Skonfiguruj przez Wi-Fi

  1. Po restarcie ekran CYD pokaże własną sieć UBox-CYD-XXXX i jej losowe hasło.
  2. Połącz telefon lub komputer z tą siecią Wi-Fi.
  3. Jeśli strona ustawień nie otworzy się automatycznie, wpisz http://192.168.4.1.
  4. Wybierz swoją domową sieć Wi-Fi 2,4 GHz i wpisz jej hasło.
  5. W polach dodatkowych wpisz IP Raspberry Pi z HA (np. 192.168.1.100, bez :8123) oraz token zdjęć z UBox Bridge.
  6. Zapisz. CYD przełączy się na domowe Wi-Fi i pobierze ostatni JPEG z Home Assistanta.

Ustawienia Wi-Fi, HA i token zapisywane są lokalnie w pamięci ESP32. Nie są przesyłane do tej witryny. Hasło sieci konfiguracyjnej jest losowane na urządzeniu.

3. Aktualizowanie zdjęcia

Home Assistant wykonuje nowe zdjęcie według interval_minutes (np. 15 minut). CYD sprawdza zapisany obraz co 30 sekund — bez wybudzania kamery LTE. Jeśli obraz się nie zmienił, pobieranie zakończy się HTTP 304.

Utrzymuj CYD i Raspberry Pi w jednej sieci lokalnej. Port 8100 dodatku UBox Bridge musi być osiągalny z CYD.

Zmiana sieci Wi-Fi lub tokenu

Przy działającym CYD przytrzymaj przycisk BOOT przez około 5 sekund, by wyczyścić lokalną konfigurację i ponownie uruchomić kreator Wi-Fi. Nie przytrzymuj BOOT podczas resetowania — to przełącza ESP32 w tryb programowania.

Jeżeli zmienisz token w panelu UBox Bridge, musisz wpisać nowy na CYD.
